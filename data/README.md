# Dataset Setup Guide: Brazilian E-Commerce Public Dataset by Olist

This project analyzes the real e-commerce dataset released by Olist on Kaggle, covering 100k orders made between 2016 and 2018 across Brazil.

## Download Instructions

1. Visit Kaggle: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
2. Download and unzip all CSV files into this `data/` folder:
   - `olist_customers_dataset.csv`
   - `olist_geolocation_dataset.csv`
   - `olist_order_items_dataset.csv`
   - `olist_order_payments_dataset.csv`
   - `olist_order_reviews_dataset.csv`
   - `olist_orders_dataset.csv`
   - `olist_products_dataset.csv`
   - `olist_sellers_dataset.csv`
   - `product_category_name_translation.csv`

> **Note:** The `.gitignore` file is configured to exclude `data/*.csv` from git commits to stay within GitHub's file size limits.
